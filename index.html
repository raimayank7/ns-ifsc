    How to use it

    1. To check a code someone gave you, type it in the first box and press Check code. You see the bank, branch and address it belongs to, so you can be sure before you send money.
    2. To find a code, type the bank name in the second box, tap the bank, choose the state, then find the branch. Tap the code to copy it.
    3. Share it: the result has a Share button that sends the code with the branch name, ready for WhatsApp.

    How an IFSC code is built

    Take SBIN0000691. SBIN is the bank (State Bank of India). The fifth character is always 0, kept for future use. 000691 is the branch. The code never has spaces, and the letter O is used only in the first four places: a round character in the fifth place is always the digit zero.

    Questions

    What is an IFSC code?

    IFSC means Indian Financial System Code. It is an 11-character code that names one bank branch: the first 4 letters are the bank, the 5th character is always zero, and the last 6 are the branch. You need it to send money by NEFT, RTGS or IMPS.

    Where do I find my IFSC code?

    On your cheque leaf (near the branch address), on the first page of your passbook, in your bank statement and in the bank's app or net banking next to your account details. You can also find it here: choose your bank, then your state and branch.

    Is this IFSC finder free?

    Yes. There is no login and no limit, and it will stay free.

    Is the IFSC code the same for all branches of a bank?

    No. Every branch has its own code. A few banks, such as payments banks, use one code for all customers.

    What if I enter a wrong IFSC code?

    If the code does not exist, the payment is refused. If it belongs to another branch of the same bank, the money usually still reaches the account, because banks match the account number. If it belongs to another bank and the account number exists there, the money can go to a stranger: tell your bank at once.

    How current is the data?

    It is from 1 September 2026, built from the lists of the Reserve Bank of India and NPCI. Branches that opened or merged after that may be missing or changed.
