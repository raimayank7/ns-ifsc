About DCB Bank IFSC codes

DCB Bank is a private sector bank. It has 483 branches with an IFSC code in 22 states and union territories. Its IFSC codes begin with DCBL. An example is DCBL0000001 (Mumbai Main Office, Mumbai).

  • Most branches: Maharashtra (86), Odisha (55), Gujarat (36), Andhra Pradesh (35), Madhya Pradesh (35).
  • Places with the most branches: Mumbai (26), Thane (12), Delhi (9), Pune (7), Ahmedabad (6), Bangalore (6).
  • 470 of 483 branches have a MICR code (the 9-digit code printed on cheques).
  • NEFT: every branch. RTGS: all but 1 branch.
  • 483 branches are listed as UPI enabled.

Questions

What is the IFSC code of DCB Bank?

Every branch of DCB Bank has its own IFSC code. The codes begin with DCBL. For example, the code of Mumbai Main Office, Mumbai is DCBL0000001. Choose the state above to see the code of each branch.

How do I find the IFSC code of my DCB Bank branch?

Choose your state on this page, then find your branch in the list or type its name in the search box. The code is also printed on your cheque book and passbook, and shown in the bank's app next to your account details.

Can I use one DCB Bank IFSC code for another branch?

Use the code of the branch where the account is held. A payment with the right account number and another branch code of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned, so always use the exact code.
