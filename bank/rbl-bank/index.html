About RBL Bank IFSC codes

RBL Bank is a private sector bank. It has 663 branches with an IFSC code in 25 states and union territories. Its IFSC codes begin with RATN. An example is RATN0000001 (Shahupuri Kolhapur, Kolhapur).

  • Most branches: Maharashtra (164), Tamil Nadu (72), Karnataka (63), Delhi (59), Gujarat (49).
  • Places with the most branches: Delhi (50), Mumbai (39), Chennai (36), Bangalore (31), Kolhapur (28), Pune (28).
  • 645 of 663 branches have a MICR code (the 9-digit code printed on cheques).
  • NEFT: every branch. RTGS: every branch.
  • 663 branches are listed as UPI enabled.

Questions

What is the IFSC code of RBL Bank?

Every branch of RBL Bank has its own IFSC code. The codes begin with RATN. For example, the code of Shahupuri Kolhapur, Kolhapur is RATN0000001. Choose the state above to see the code of each branch.

How do I find the IFSC code of my RBL Bank branch?

Choose your state on this page, then find your branch in the list or type its name in the search box. The code is also printed on your cheque book and passbook, and shown in the bank's app next to your account details.

Can I use one RBL Bank IFSC code for another branch?

Use the code of the branch where the account is held. A payment with the right account number and another branch code of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned, so always use the exact code.
