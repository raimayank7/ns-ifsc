About Salal Sarvodaya Nagarik Sahakari Bank IFSC codes

Salal Sarvodaya Nagarik Sahakari Bank is a urban co-operative bank. It has 1 branch with an IFSC code in 1 state or union territory. Its IFSC codes begin with GSCB, the bank code of Gujarat State Co-operative Bank. Smaller banks often send and receive NEFT and RTGS payments through a larger bank (a sub-member arrangement), and their IFSC codes then carry that bank's four letters. An example is GSCB0USSNPL (Salal Sarvodaya Nagarik Sahakari Bank Imps, Mumbai).

Can I use one Salal Sarvodaya Nagarik Sahakari Bank IFSC code for another branch?

Use the code of the branch where the account is held. A payment with the right account number and another branch code of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned, so always use the exact code.
