About Sitamarhi Central Co-operative Bank IFSC codes

Sitamarhi Central Co-operative Bank is a district central co-operative bank. It has 1 branch with an IFSC code in 1 state or union territory. Its IFSC codes begin with IBKL, the bank code of IDBI. Smaller banks often send and receive NEFT and RTGS payments through a larger bank (a sub-member arrangement), and their IFSC codes then carry that bank's four letters. An example is IBKL0719SCB (Sitamarhi Central Co-operative Bank Imps, Mumbai).

Questions

What is the IFSC code of Sitamarhi Central Co-operative Bank?

Every branch of Sitamarhi Central Co-operative Bank has its own IFSC code. The codes begin with IBKL. For example, the code of Sitamarhi Central Co-operative Bank Imps, Mumbai is IBKL0719SCB. Choose the state above to see the code of each branch.

How do I find the IFSC code of my Sitamarhi Central Co-operative Bank branch?

Choose your state on this page, then find your branch in the list or type its name in the search box. The code is also printed on your cheque book and passbook, and shown in the bank's app next to your account details.

Can I use one Sitamarhi Central Co-operative Bank IFSC code for another branch?

Use the code of the branch where the account is held. A payment with the right account number and another branch code of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned, so always use the exact code.
