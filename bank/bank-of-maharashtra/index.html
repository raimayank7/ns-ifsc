About Bank of Maharashtra IFSC codes

Bank of Maharashtra is a public sector bank. It has 2,903 branches with an IFSC code in 36 states and union territories. Its IFSC codes begin with MAHB. An example is MAHB0000001 (Pune-Bajirao Road, Pune).

  • Most branches: Maharashtra (1,221), Madhya Pradesh (202), Uttar Pradesh (173), Gujarat (123), Tamil Nadu (122).
  • Places with the most branches: Pune (238), Nasik (89), Thane (61), Satara (61), Ahilyanagar (52), Mumbai Suburban (48).
  • 2,864 of 2,903 branches have a MICR code (the 9-digit code printed on cheques).
  • NEFT: all but 1 branch. RTGS: all but 2 branches.
  • 2,903 branches are listed as UPI enabled.

Questions

What is the IFSC code of Bank of Maharashtra?

Every branch of Bank of Maharashtra has its own IFSC code. The codes begin with MAHB. For example, the code of Pune-Bajirao Road, Pune is MAHB0000001. Choose the state above to see the code of each branch.

How do I find the IFSC code of my Bank of Maharashtra branch?

Choose your state on this page, then find your branch in the list or type its name in the search box. The code is also printed on your cheque book and passbook, and shown in the bank's app next to your account details.

Can I use one Bank of Maharashtra IFSC code for another branch?

Use the code of the branch where the account is held. A payment with the right account number and another branch code of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned, so always use the exact code.
