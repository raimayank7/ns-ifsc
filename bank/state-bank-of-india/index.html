About State Bank of India IFSC codes

State Bank of India is a public sector bank. It has 26,483 branches with an IFSC code in 35 states and union territories. Its IFSC codes begin with SBIN. An example is SBIN0000001 (Kolkata Main, Kolkata).

  • Most branches: Andhra Pradesh (2,733), Uttar Pradesh (2,697), Maharashtra (2,105), Karnataka (1,792), Rajasthan (1,599).
  • Places with the most branches: Bangalore Urban (320), New Delhi (297), Kolkata (282), Chennai (272), Jaipur (248), Greater Bombay (244).
  • 25,199 of 26,483 branches have a MICR code (the 9-digit code printed on cheques).
  • NEFT: every branch. RTGS: all but 820 branches.
  • 26,483 branches are listed as UPI enabled.
  • 749 branches have a SWIFT code for money from abroad.

Questions

What is the IFSC code of State Bank of India?

Every branch of State Bank of India has its own IFSC code. The codes begin with SBIN. For example, the code of Kolkata Main, Kolkata is SBIN0000001. Choose the state above to see the code of each branch.

How do I find the IFSC code of my State Bank of India branch?

Choose your state on this page, then find your branch in the list or type its name in the search box. The code is also printed on your cheque book and passbook, and shown in the bank's app next to your account details.

Can I use one State Bank of India IFSC code for another branch?

Use the code of the branch where the account is held. A payment with the right account number and another branch code of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned, so always use the exact code.
