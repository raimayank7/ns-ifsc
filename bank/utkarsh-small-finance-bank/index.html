About Utkarsh Small Finance Bank IFSC codes

Utkarsh Small Finance Bank is a small finance bank. It has 1,118 branches with an IFSC code in 27 states and union territories. Its IFSC codes begin with UTKS. An example is UTKS0000001 (Utkarsh Small Finance Bank Imps, Mumbai).

  • Most branches: Bihar (283), Uttar Pradesh (231), Odisha (104), Jharkhand (99), Maharashtra (87).
  • Places with the most branches: Patna (18), Varanasi (16), Mirzapur (15), Gorakhpur (15), Saran (13), Siwan (12).
  • 1,103 of 1,118 branches have a MICR code (the 9-digit code printed on cheques).
  • NEFT: every branch. RTGS: every branch.
  • 1,118 branches are listed as UPI enabled.

Questions

What is the IFSC code of Utkarsh Small Finance Bank?

Every branch of Utkarsh Small Finance Bank has its own IFSC code. The codes begin with UTKS. For example, the code of Utkarsh Small Finance Bank Imps, Mumbai is UTKS0000001. Choose the state above to see the code of each branch.

How do I find the IFSC code of my Utkarsh Small Finance Bank branch?

Choose your state on this page, then find your branch in the list or type its name in the search box. The code is also printed on your cheque book and passbook, and shown in the bank's app next to your account details.

Can I use one Utkarsh Small Finance Bank IFSC code for another branch?

Use the code of the branch where the account is held. A payment with the right account number and another branch code of the same bank usually still arrives, because banks match the account number, but it can be delayed or returned, so always use the exact code.
